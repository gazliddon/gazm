## Expected a Register

A valid register was expected. These are the valid registers for the 6800:

| Register | Bits | Notes                    |
|:--------:|:----:|:-------------------------|
| A        | 8    | A accumulator            |
| B        | 8    | B accumulator            |
| X        | 16   | X index register         |
| SP       | 16   | Stack pointer            |
| PC       | 16   | Program counter          |
| SR       | 8    | Condition code register  |

Gazm allows registers to be either lower or upper case.
